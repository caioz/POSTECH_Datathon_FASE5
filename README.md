
# 🎓  Datathon — Fase 5  
## Passos Mágicos - Análise educacional

Este repositório contém a entrega final do **Datathon - Fase 5** do curso de pós-graduação em Data Analytics, no qual o objetivo principal foi analisar o desempenho de alunos ao longo do tempo e desenvolver uma solução preditiva capaz de identificar, de forma antecipada, alunos em risco de defasagem acadêmica.

---

## 🎯 Objetivo do Projeto

O desafio consiste na análise de dados educacionais da **Associação Passos Mágicos**, uma organização com mais de 30 anos de atuação dedicada à transformação da vida de crianças e jovens em situação de vulnerabilidade social por meio da educação.

Foram realizadas as seguintes entregas:

- Análise diagnóstico de 11 perguntas de negócio apresentadas no briefing;
- Uma aplicação preditiva interativa desenvolvida em Streamlit;
- Apresentação executiva respondendo as principais dores do negócio e realizando recomendações.

---

## 🎲 Fonte dos Dados

Os dados utilizados neste projeto estão disponíveis no arquivo **BASE DE DADOS PEDE 2024 - DATATHON**, fornecido no contexto do Datathon.

**Principais indicadores:**

| Indicador | Descrição |

| **IPS** | Indicador Psicossocial |
